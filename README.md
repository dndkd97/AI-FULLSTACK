**완벽보다 완성을.** 기획부터 배포까지, 사용자 흐름을 직접 설계하고 끝까지 책임지는 개발자를 목표로 6개월간 달려왔습니다.

- 혼자 학습하는 것에 그치지 않고 **GitHub 협업 워크플로우**(브랜치 전략, PR 리뷰)를 익혀 팀 개발 감각을 키웠습니다  
- 이론에 머무르지 않고 **AWS EC2 배포까지 직접 경험**하며 "만들고 끝"이 아닌 "운영까지 책임지는" 개발자로 성장했습니다

앞으로는 브랜치 전략과 CI/CD 파이프라인을 더 심도 있게 학습하고, AI 모델과 풀스택 서비스를 결합한 프로젝트로 역량을 확장해나갈 계획입니다.

## 🚀 대표 프로젝트

### SpringBreeze ERP — 사내 통합 ERP 시스템

교육과정에서 4인 팀으로 진행한 프로젝트. 담당 모듈: **프로젝트 / 프로젝트 멤버 / 태스크 / 공지** → 이후 **채용관리(RAG)** 모듈과 **채용 데이터 분석 서버**를 단독 설계·구축.
상세 구현 내용과 트러블슈팅 기록은 각 버전 저장소의 README에 정리되어 있습니다.

|---|---|---|
| v4 | Python + Django + Pandas + AWS EC2/Nginx/GitHub Actions (단독) | [SBErpV4](https://github.com/dndkd97/sberp) |
